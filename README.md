> **RAJ MUSIC BOT** is a Telegram voice-chat music bot customized and maintained by **Rajbots**. It is built with Python, Pyrogram, and Py-Tgcalls for a smooth music experience inside Telegram groups.

## ✨ Features

- 🎶 Play music directly in Telegram group voice chats
- 🔎 Search and stream music from supported platforms
- ▶️ Queue-based playback with play and playlist support
- 📻 Support for live streams
- 🎧 YouTube, Spotify, Apple Music, SoundCloud, Resso, and Telegram platform helpers
- ⚡ Fast Pyrogram-based Telegram interface
- 🗄️ MongoDB-backed data and settings
- 🛡️ Admin, ban, filter, notes, AFK, and moderation utilities
- 🌍 Multi-language string support
- 🐳 Docker, Heroku, and worker-process deployment files included

## 🧰 Tech Stack

| Technology | Purpose |
| --- | --- |
| Python | Core application language |
| Pyrogram / Pyrofork | Telegram client and bot API |
| Py-Tgcalls | Voice-chat audio and stream handling |
| MongoDB | Persistent bot data |
| FFmpeg | Audio/video processing |
| yt-dlp | Media extraction and downloading |

## 🚀 Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/rajfflive/RAJMUSICBOT.git
cd RAJMUSICBOT
```

### 2. Install system requirements

Make sure the following are installed:

- Python 3.10 or newer
- FFmpeg
- Git
- MongoDB database

On Debian/Ubuntu:

```bash
sudo apt update
sudo apt install -y python3 python3-pip ffmpeg git
```

### 3. Install Python dependencies

```bash
pip3 install -U pip
pip3 install -r requirements.txt
```

### 4. Configure environment variables

Copy the example file:

```bash
cp sample.env .env
```

Then open `.env` and fill in your own values:

```env
API_ID=
API_HASH=
BOT_TOKEN=
LOGGER_ID=
MONGO_DB_URI=
OWNER_ID=
STRING_SESSION=
SUPPORT_CHAT=https://t.me/numinfogc
SUPPORT_CHANNEL=https://t.me/+CsV2G4MFfBBkNjM9
START_IMG_URL=https://kommodo.ai/i/GXY5yBlCZcmZFVnJnl1E
```

### 5. Start the bot

```bash
bash start
```

The optional interactive installer can also prepare dependencies and generate the environment file:

```bash
bash setup
```

## 🔐 Required Credentials

| Variable | Description |
| --- | --- |
| `API_ID` | Telegram API ID from [my.telegram.org](https://my.telegram.org) |
| `API_HASH` | Telegram API hash from [my.telegram.org](https://my.telegram.org) |
| `BOT_TOKEN` | Bot token generated by [@BotFather](https://t.me/BotFather) |
| `LOGGER_ID` | Telegram log group or channel ID |
| `MONGO_DB_URI` | MongoDB connection URI |
| `OWNER_ID` | Telegram user ID of the bot owner |
| `STRING_SESSION` | Pyrogram userbot session string |
| `SUPPORT_CHAT` | Support group URL |
| `SUPPORT_CHANNEL` | Support or update channel URL |

> **Security note:** Never commit `.env`, bot tokens, API credentials, session strings, or database credentials to GitHub. Keep them in your hosting provider's environment settings.

## 🐳 Docker Deployment

The repository includes a `Dockerfile` with FFmpeg and the Python dependencies configured.

```bash
docker build -t raj-music-bot .
docker run --env-file .env raj-music-bot
```

## ☁️ Heroku-Style Deployment

The project includes `Procfile` and `heroku.yml` configuration for worker-based hosting. Add all variables from `.env` to your hosting provider's config vars, then deploy the `worker` process.
